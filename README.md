## Instrucciones

1. Clonar este repositorio en una carpeta del comptador.
2. En Eclipse ir a: File → Import → General → Existing Projects into Workspace → Buscar la carpeta en donde se clonó el repositorio → Finish
3. Importar el perfil de formato de código:

Window → Preferences → Java → Code Style → Formatter
   → Import… → seleccionar eclipse-config/gr9-formato-java.xml
   → Establecerlo como Active Profile

4. Hacer click derecho en el projecto en eclipse → Properties → Java Code Style → Formatter → Activar "Enable project specific settings" → gr9-formato-java.xml profile debería estar seleccionado.
