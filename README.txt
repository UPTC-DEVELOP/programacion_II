CRUD DE LIBROS - PROGRAMACION II UPTC - UNIDAD 2

Importar en Eclipse:
1. Descomprimir.
2. Eclipse > File > Import > General > Existing Projects into Workspace.
3. Seleccionar esta carpeta.
4. Ejecutar src/com/tiendavirtual/Main.java como Java Application.

Incluye:
- Frontend Java Swing.
- Backend con Controller + Service + Repository en memoria.
- POO y separación por responsabilidades.
- Registrar, actualizar, listar y eliminar.
- Validaciones de ISBN, campos, año, páginas, precio, stock y formato.
- Regla: no eliminar si tiene ventas asociadas.
- IVA 19% o 5% y cálculo de precio final.
- PruebasCrud.java para demostrar las operaciones.

No hay persistencia, porque la guía de Unidad 2 indica que por el momento solo se requiere frontend y backend.
